# Screenshots

This folder contains screenshots for the TrustRent project README.

## How to Add Screenshots

1. Start the app: `npm run dev`
2. Open `http://localhost:3000` in your browser
3. Capture the following pages:
   - **mobile-dashboard.png** — Dashboard at 375px width (iPhone SE)
   - **desktop-dashboard.png** — Dashboard at 1280px width
   - **agreement-detail.png** — Agreement detail page (AG-1042)
   - **disputes-page.png** — Disputes page
   - **role-switcher.png** — Role switcher toggling landlord ↔ tenant
   - **evidence-upload.png** — Move-out evidence upload page
4. Save them as PNG files in this folder
5. Go to the project root `README.md` and uncomment the image tags in the "Screenshots" section

## File Naming Convention

Use lowercase with hyphens: `mobile-dashboard.png`, `agreement-detail.png`, etc.
