# Integration tests

Placeholder for end-to-end coverage. Strategy for phase 2:

## Contract-level (Rust)

Each contract ships `#[cfg(test)]` unit tests using the Soroban test harness
(`Env::default()` + clients). Cross-contract flows (agreement → escrow →
dispute) will be tested by registering all three contracts in one `Env` and
driving the state machine end to end.

## API + chain

Once `@trustrent/blockchain` is wired, the API can point at a local
`soroban test` sandbox or the public testnet and run:

- create agreement → tenant joins → deposit locks
- move-out flow through to full refund
- dispute with deduction split

Fixtures (generated by `npm run seed` in `scripts/`) live in
`tests/fixtures/`.
